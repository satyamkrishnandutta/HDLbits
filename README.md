# HDLBits Verilog Solutions & Hardware Showcase

![Verilog](https://img.shields.io/badge/Language-Verilog_2001-blue.svg)
![Status](https://img.shields.io/badge/Progress-In_Progress-orange.svg)
![Platform](https://img.shields.io/badge/Platform-HDLBits-brightgreen.svg)

A complete repository containing verified solution sets, hardware design patterns, and testbenches for all ~180 problems on [HDLBits](https://hdlbits.01xz.net/wiki/Main_Page). 

The goal of this repository is to systematically master **RTL design**, **Verilog syntax**, and **sequential/combinational digital logic circuit design**.
